# MPU6050_I2C
This is the library for using the I2C implementation with MPU6050 on Arduino.

Files `src` should NOT be edited directly here.

The script `sync_mpu6050_lib.bat` will copy headers and source from `c/mpu6050_i2c/src` to the `src` here and copy this folder to Arduino libraries folder.
* RUN IN PROJECT ROOT
